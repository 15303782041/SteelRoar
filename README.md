# SteelRoar

基于 **Unity 3D** 开发的坦克生存射击游戏（个人独立开发，开发中）。

## 游戏简介

驾驶坦克在无尽波次的敌人攻势下生存：击毁敌方坦克获得分数与金币，每波间隙从随机出现的强化零件中三选一构筑流派，对抗每 5 波一次的 Boss 挑战。

## 操作方式

| 按键 | 功能 |
|------|------|
| W / S | 前进 / 后退 |
| A / D | 车体转向 |
| 鼠标移动 | 炮台瞄准 |
| 鼠标左键 | 开火 |
